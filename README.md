# Akari's Little World

A playful, paper-inspired portfolio starter built with Next.js, TypeScript, CSS, and Framer Motion.

## Quick start

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Where to edit content

All placeholder content is centralized in:

`app/data.ts`

You can add/remove/reorder:

- `projects`
- `experiences`
- `playgrounds`

The visual components are intentionally separate from the content data.

## Main components

`components/LittleWorld.tsx`

Contains the page flow and reusable visual components:

- `TopNav`
- `JourneyPlane`
- `SectionKicker`
- `StickyNote`
- `ProjectCard`
- `PlaygroundCard`
